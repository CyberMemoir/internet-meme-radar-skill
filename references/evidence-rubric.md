# Evidence Rubric

Use this rubric when a request depends on whether a meme is current, widespread, or correctly attributed.

## Source tiers

| Tier | Evidence | Best use |
|---|---|---|
| A | Original post, official account, platform trend page, official API | Dates, wording, creator identity, visible metrics |
| B | Multiple independent recent posts and their comments | Actual usage, spread, audience interpretation |
| C | Reputable reporting, interviews, research, archived explainers | Context and origin corroboration |
| D | Search snippets, reposts, aggregators, unsourced explainers | Discovery only; corroborate before relying on it |

Do not treat engagement alone as proof of adoption. A famous creator's isolated post can have high engagement without creating a reusable meme.

## Claim-to-evidence rules

- **Meaning:** require at least two contextual uses or one direct explanation plus one use.
- **Origin:** prefer the earliest verifiable artifact; distinguish creation from later popularization.
- **Current status:** require dated evidence from the relevant platform and time window.
- **Cross-platform spread:** require independent examples on each named platform.
- **Audience interpretation:** use comment patterns only when comments are numerous enough to show repetition rather than one person's guess.

## Recency windows

Choose a window before searching and state it when it affects the conclusion:

- Fast-moving audio, challenge, or short-video format: last 7–30 days.
- Slang or reaction phrase: last 30–90 days.
- Origin tracing: search backward without a fixed cutoff.
- Historical or revived meme: compare the original wave with the last 30–90 days.

## Evidence ledger

Keep compact notes while researching:

```yaml
claim: ""
source_url: ""
platform: ""
published_at: ""
observed_at: ""
source_tier: A|B|C|D
supports: meaning|origin|status|spread|tone
limitations: ""
```

Resolve contradictions explicitly. Prefer primary, dated, contextual evidence over repeated unsourced claims.
