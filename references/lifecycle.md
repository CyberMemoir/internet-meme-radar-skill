# Trend Lifecycle

Classify status only after defining the target platform, community, and time window.

| Label | Observable pattern |
|---|---|
| Emerging | Recent appearances from a few independent creators; reuse has started but remains sparse |
| Rising | Creator diversity, reuse frequency, or comment adoption is increasing within the chosen window |
| Mainstream | Broad recognition and reuse across unrelated creators or communities |
| Niche | Stable use inside one fandom, region, profession, or subculture without broad diffusion |
| Declining | New examples still exist, but reuse or creator diversity is visibly below the previous wave |
| Outdated | Mostly referenced nostalgically, explained to newcomers, or used as deliberate throwback irony |
| Revived | An older format has a distinct new wave, trigger, audience, or remix style |
| Manufactured | Distribution is dominated by ads, coordinated promotion, or near-identical seeded posts |
| Unknown | Accessible evidence cannot support a lifecycle judgment |

## Avoid false trend calls

- Separate raw views from reusable-format adoption.
- Deduplicate reposts and compilation accounts.
- Do not mistake a fandom spike for platform-wide popularity.
- Compare publication dates, not search-result order.
- Treat recommendation feeds as personalized samples, not representative rankings.
- Distinguish a phrase being discussed from the phrase being naturally used.

## Compare waves

For revivals, report:

1. the earliest verifiable wave;
2. the trigger for the new wave, if supported;
3. what changed in meaning, format, or audience;
4. whether the revival is platform-specific.
